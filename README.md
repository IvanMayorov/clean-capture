# Clean Capture

Расширение для Chrome: копирование страницы или выбранного элемента сайта в редактируемые слои Figma.

Версия **0.1.13**. Экспериментальная неофициальная сборка на основе Figma extension 1.3.27. Для работы достаточно расширения Chrome; отдельный Figma-плагин не требуется.

## Установка

1. Скачайте **clean-capture-chrome-v0.1.13.zip** из [последнего релиза](https://github.com/IvanMayorov/clean-capture/releases/latest) и распакуйте архив в постоянную папку.
2. Откройте `chrome://extensions` в Chrome.
3. Включите **Режим разработчика**.
4. Нажмите **Загрузить распакованное расширение** и выберите папку `extension`, внутри которой находится `manifest.json`.
5. При желании закрепите Clean Capture через меню расширений Chrome.

Альтернативный способ: **Code → Download ZIP**, распаковать репозиторий и выбрать его папку `extension`. Сборка и установка зависимостей не нужны. Chrome 116 или новее.

## Использование

1. Откройте нужный сайт и нажмите значок Clean Capture.
2. При необходимости нажмите **Отключить анимации** (⏸ на узком экране). Кнопка ▶ возвращает анимации.
3. Выберите **Capture design** для страницы или **Select element** для отдельного блока.
4. После копирования вставьте результат в Figma: **⌘V** на macOS или **Ctrl+V** на Windows/Linux.

Расширение убирает CSS Grid и flex у обычных контейнеров, сохраняет их координаты и оформление, очищает простые обёртки. У кнопок flex сохраняется. Разбитый на спаны текст объединяется там, где можно сохранить форматирование. Отключение анимаций поддерживает распространённые эффекты появления, но произвольный код сайта может потребовать дополнительной обработки. Сложные страницы могут отличаться после импорта.

Если локальный шрифт не найден, появится **Скачать шрифт**. Расширение подготавливает ZIP с TTF/OTF и лицензией; распакуйте его, установите шрифт средствами системы и перезапустите Figma. Geologica и Inter Tight встроены в расширение. Другие семейства ищутся в открытом каталоге Google Fonts. Автоматическая установка шрифтов не выполняется.

Для локальных HTML-файлов включите доступ к `file://` в настройках расширения. На служебных страницах Chrome расширения не работают.

## Обновление

Скачайте новый релиз, замените содержимое папки расширения, нажмите ↻ у Clean Capture в `chrome://extensions` и обновите вкладку сайта. Установка из GitHub автоматически не обновляется. Не удаляйте папку после установки: Chrome загружает расширение из неё.

## Разрешения и данные

- `activeTab`, `scripting`: чтение и обработка открытой страницы после нажатия значка расширения.
- `clipboardWrite`: запись захваченного дизайна в буфер обмена.
- `storage`, `unlimitedStorage`: локальная история снимков, включая изображения, без стандартного лимита 10 МБ. Это не снимает ограничения свободного места на диске.
- `downloads`: сохранение архивов шрифтов после нажатия кнопки скачивания.
- Необязательный доступ к сайтам: восстановление внешних изображений после отдельного разрешения пользователя.

Захват обрабатывается в браузере, история хранится локально. Вызовы аналитики исходной панели отключены. При восстановлении изображений браузер обращается к их адресам; исходный механизм обработки изображений также содержит адрес прокси Figma. По кнопке скачивания шрифтов имя гарнитуры используется для поиска файлов на `raw.githubusercontent.com/google/fonts`; содержимое захвата для этого не отправляется.

## Состав и авторство

В репозитории только готовое расширение Chrome и эта инструкция. Figma-плагинов, захватов пользовательских страниц и личных макетов здесь нет.

Это не официальный продукт Figma и не публикация в Chrome Web Store. Происхождение сборки указано в [UPSTREAM.txt](extension/UPSTREAM.txt). Права на исходный код и сторонние компоненты сохраняются за их правообладателями; общей открытой лицензии на этот репозиторий не заявляется. Встроенные шрифты распространяются с файлами OFL в `extension/fonts`.
